# Fearsome Sentinel

Маленький установщик и обновлятор для [Fearsome](https://github.com/pukpukpuk/fearsome) — клиентского мода, необходимого для игры в Fear: GOTY Edition.

Закиньте этот jar в папку `mods`, и при следующем запуске он установит Fearsome вместе со всем необходимым. При последующих запусках он будет поддерживать Fearsome в актуальном состоянии.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/) для Minecraft 1.21.11.
2. Скачайте последний `FearsomeSentinel-*.jar` из [Releases](https://github.com/pukpukpuk/fearsome-sentinel/releases) и положите его в папку с модами.
3. Запустите игру, нажмите **Установить**, дождитесь загрузки и запустите игру снова.
