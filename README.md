# Fearsome Sentinel

A tiny installer and updater for [Fearsome](https://github.com/pukpukpuk/fearsome), the client-side mod required to play Fear: GOTY Edition.

Drop this one jar into your `mods` folder, and on the next launch it installs Fearsome along with everything it needs. Later launches keep Fearsome up to date.

## Installation

1. Install Fabric for Minecraft 1.21.11.
2. Download the latest `FearsomeSentinel-*.jar` from [Releases](https://github.com/pukpukpuk/fearsome-sentinel/releases) and put it into mods folder.
3. Launch the game, click **Install**, wait for the download, then launch the game again.
